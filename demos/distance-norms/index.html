Distance Norms in Robot Workspace and Phase Space

This Demonstration shows the area within the distance d of a two-link planar-arm robot with configuration (θ1, θ2). The distance d is measured in the L1, L2, L3 or L∞ norm, with the norm applied either in the workspace or the phase space of the robot. You can change the norm type, the length of the first arm joint and the angles of the two arm joints.

Details

The measurement of distance between two configurations of the same robot is necessary for many robot motion planners, such as probabilistic road-map methods and rapidly expanding random trees.

The vector norm |x|p for p=1,2,… is defined as |x|p= ∑i|xi|p1/p.

The special case for p=∞ is defined as |x|∞=maxi|xi|.

If a given robot configuration (θ1*,θ2*) places the tip of the robot at position (xr,yr), the workspace norms are L1=|xr−x|+|yr−y|, L2=(xr−x)2+(yr−y)2, L3=|xr−x|3+|yr−y|33 and L∞=max(|xr−x|,|yr−y|).

It is trivial to compute the distance using norms in the workspace; however, these distances are often misleading. The arm's workspace is the unit disk, but the L∞<1/2 workspace norm shown in Snapshot 1 includes an area inaccessible to the robot arm.

It is more correct to calculate the set of configurations with distance less than d in the phase space of the robot and then map this set into the workspace. These norms are L1=|θ1*−θ1|+|θ2*−θ2|, L2=(θ1*−θ1)2+(θ2*−θ2)2, L3=|θ1*−θ1|3+|θ2*−θ2|33 and L∞=max(|θ1*−θ1,|θ2*−θ2|). The mapping into the workspace is performed using Mathematica's ParametricPlot command.

Notice that lower-order norms are contained by higher-order norms: L1⊆L2⊆L3⊆L∞.
