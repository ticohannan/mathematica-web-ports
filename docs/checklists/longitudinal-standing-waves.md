# Manual checks — Longitudinal Standing Waves (`demos/longitudinal-standing-waves/`)

Each item compares the original in Mathematica with the port, as an operator procedure (rule 8); the general
procedure is in [`docs/MATHEMATICA_CHECKS.md`](../MATHEMATICA_CHECKS.md). Record every result in the test-run file
`_internal\test-runs\<YYYY-MM-DD>_longitudinal-standing-waves.md` (create it with `npm run test-run -- longitudinal-standing-waves`). Generated by
`tools/new-app.mjs`; items 05 and later added with the port (v0.1.41).

Original notebook (all items): `_internal\originals\wolfram-2026-11-17\LongitudinalStandingWaves.nb`.
Port (all items): `http://127.0.0.1:8080/demos/longitudinal-standing-waves/` (after `npm run serve`).
The controls are at the top of the Manipulate panel: the row "harmonic *n*" (buttons 1 … 7), the row "pipe end" (open, closed, none), the row "options" (ten toggle buttons: +, →, ←, |||||, ⋮⋮⋮⋮⋮, a small blue wave, ≡≡, ⋰⋱, displacement nodes, pressure nodes; a pressed button is light) and the row "time *t*" (▶ and two speed buttons).
