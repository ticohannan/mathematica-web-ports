### [Title]
Graham Scan to Find the Convex Hull of a Set of Points in 2D

### [Section]
Caption<<PaneSelectorBox>>

### [Text]
This Demonstration shows the steps of the Graham scan, an algorithm to find the convex hull of a finite set of points in 2D. The method has time complexity O(n log n) for n points. You can drag the points to change their positions, move the step slider to step through the algorithm or generate n new points for a new problem.

Manipulate[Module[{pts,stPt,slopeOrder,convexHullPts,droppedLines={}},
(* Initialize system *) 
stPt =First@MaximalBy[MinimalBy[Allpts,Last],First];
(* Start with the lowest point. If multiple points have the same minimum y, use the rightmost. *)
pts = Delete[Allpts,First@@Position[Allpts,stPt]];
stPt = stPt+{0,-0.001};(* Avoid numerical instability with many points at y-minimum. You could instead sort them by x, but that would need another sort step. *)
slopeOrder = Ordering[Table[If[pts[[i,2]]==stPt[[2]],-∞,(stPt[[1]]-pts[[i,1]])/(pts[[i,2]]-stPt[[2]])],{i,1,Length[pts]}]];
If[iMax > Length[pts],iMax = Length[pts]];
(* ========Start Computation for Convex Hull======== *)
convexHullPts = {stPt,pts[[slopeOrder[[1]]]]};
Table[
droppedLines = {};
While[ isLeftTurn[convexHullPts[[-2]],convexHullPts[[-1]],pts[[slopeOrder[[i]]]]]<0,
AppendTo[droppedLines ,{convexHullPts[[-2]],convexHullPts[[-1]]}]; (* Added so we can plot the points that are removed. *)
convexHullPts = Drop[convexHullPts,-1](*Remove steps*)
];
AppendTo[convexHullPts,pts[[slopeOrder[[i]]]]],
{i,2,iMax}];
If[iMax==Length[pts],AppendTo[convexHullPts,stPt]]; (*Added to pause the computation so you can see the steps.*)
(* ========End Computation for Convex Hull+======== *)

(* ========Draw process======== *)
Graphics[{
{Dashed,Red,Line[droppedLines]},
{Thick, Blue,Line[Most[convexHullPts]], Dashed,Line[{convexHullPts[[-1]],convexHullPts[[-2]]}]},
Table[{Hue[(i-1)/(1.1Length[pts])](*ColorData["\<Rainbow\>",(i-1)/(Length[pts])]*),Line[{stPt,pts[[slopeOrder[[i]]]]}]
},{i,1,iMax}],

Details & Citations<<PaneSelectorBox>>

### [Text]
The first step is to find the point with the lowest y coordinate. This is the starting point of the convex hull. (If more than one point has this value, the rightmost one is used). Second, all the remaining points are sorted by polar angle from the starting point. This can be accomplished without trigonometry by using the reciprocal of the slope (\[Dash]run/rise); use negative infinity if the points have the same y coordinate. Call this list sortedPoints.

### [Text]
\<The algorithm then considers each sorted point in sequence, which you can animate by moving the "step" slider.\>

### [Text]
A stack called convexHull is maintained, initialized with the starting point and the first sorted point. For every additional point in sortedPoints, we determine if connecting to this point from the convexHull required a left turn or a right turn. If a right turn was required, points are popped off the stack convexHull until connecting to the current point in sortedPoints requires a left turn (the removed lines from convexHull are drawn as dashed red lines). This point is then added to convexHull, and the process is repeated until all the points in sortedPoints have stepped through.

### [Text]
The function isLeftTurn[] returns the signed area of the triangle defined by the points p, q, r. If this area is positive, then going from pq to qr is a left turn. If the area is negative, it is a right turn. The area computation is the determinant of a 3\[Cross]3 matrix, and so requires no trigonometric functions.
