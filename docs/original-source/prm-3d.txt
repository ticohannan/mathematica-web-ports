### [Text]
\<This Demonstration uses the probabilistic roadmap method (PRM) to plan a motion path for a three-link robot in a 3D configuration space that avoids collisions with a blue and a yellow sphere. If a path from the initial configuration to the goal configuration is found, it can be traversed by moving the "progress" slider. To generate a new roadmap, click "restart" and then click "add 100 vertices" to randomly sample configurations and calculate if they collide with obstacles (red points) or are safe (green points). If no path is found, continue adding vertices or increase the "radius" value to try to connect safe vertices less than radius distance apart into a roadmap. Although the PRM does not need to calculate the configuration space obstacles, you can make them visible with a checkbox.\>

wrapto0to2π[x_]:= If[x>2π,x-2π,If[x<0,x+2π,x]]

### [Input] (init)
pathOKTrobot[ps_,pe_,pObs3_,obsRad_,widtha_,delta_]:=Module[{dist,n,pt,dx,dx2,dy,dy2,dz,dz2},
(*Returns tr*)
(*Toroid assumption*)
dx = Abs[pe[[1]]-ps[[1]]];
dx2 =2π- dx;
dy = Abs[pe[[2]]-ps[[2]]];
dy2 =2π-dy ;
dz = Abs[pe[[3]]-ps[[3]]];
dz2 =2π-dz ;

dx=pe[[1]]-ps[[1]]+If[dx<dx2,0, If[pe[[1]]>ps[[1]],-2π,+2π]];
dy=pe[[2]]-ps[[2]]+If[dy<dy2,0, If[pe[[2]]>ps[[2]],-2π,+2π]];
dz=pe[[3]]-ps[[3]]+If[dz<dz2,0, If[pe[[3]]>ps[[3]],-2π,+2π]];

dist = Sqrt[dx^2+dy^2+dz^2];
If[dist<= delta,
True,
n=Ceiling[dist/delta];
!Or@@Table[pt = ps+ {dx,dy,dz}*(i)/(n+1);
pt[[1]]=wrapto0to2π[pt[[1]]];
pt[[2]]=wrapto0to2π[pt[[2]]];
pt[[3]]=wrapto0to2π[pt[[3]]];
detCollision[jointAngle2Origin[pt],pObs3,obsRad,widtha] ,{i,1,n}]]
]

+Min[(#1[[3]]-#2[[3]])^2,(2π-Abs[#1[[3]]-#2[[3]]])^2])&)

myAstar[adjL_,verts_,si_,fi_]:=Module[{openSet,cameFrom,gScore,fScore,current,currentfscore,path,tentativegScore},
(*The set of discovered nodes that may need to be (re-)expanded. Initially, only the start node is known.*)
openSet={si};
cameFrom  = ConstantArray[-1, Length[verts]]; (*For node n,cameFrom[n] is the node immediately preceding it on the cheapest path from start to n currently known.*)
gScore = ConstantArray[∞, Length[verts]]; (*For node n,gScore[n] is the cost of the cheapest path from start to n currently known.*)
gScore[[si]] = 0;
(*For node n,fScore[n]:=gScore[n]+h(n).*)
fScore= ConstantArray[∞, Length[verts]]; (*map with default value of Infinity*)
fScore[[si]]=toroidDist[verts[[si]] , verts[[fi]]];
While[Length[openSet]>0 (*&& ctr<10*),
(*current:=the node in openSet having the lowest fScore[] value*)
currentfscore = Min[fScore[[openSet]]];
current =openSet[[ First@@Position[fScore[[openSet]],currentfscore]]];

If[ current == fi,
path = {fi};While[First@path!=si,PrependTo[path,cameFrom[[First@path]]]];
Return[path]
];
openSet = DeleteCases[openSet,current];
Table[
tentativegScore = gScore[[current]]+toroidDist[verts[[current]],verts[[nbr]]];
If[tentativegScore< gScore[[nbr]],
          (*This path to neighbor is better than any previous one. Record it!*)
cameFrom[[nbr]]=current;
gScore[[nbr]]=tentativegScore;fScore[[nbr]]=gScore[[nbr]]+toroidDist[verts[[nbr]] , verts[[nbr]]];
If[ FreeQ[openSet,nbr],AppendTo[openSet,nbr]]];
,{nbr,adjL[[current]]}];
];	
Return[-1]  (*Failure*)
]

### [Input] (init)
toroidLine[e_,color1_:Blue,color2_:-1]:=Module[{dx,dx2,dy,dy2,dz,dz2},
dx = Abs[e[[2,1]]-e[[1,1]]];
dx2 =2π- dx;
dy = Abs[e[[2,2]]-e[[1,2]]];
dy2 =2π- dy ;
dz = Abs[e[[2,3]]-e[[1,3]]];
dz2 =2π- dz ;
If[dx>dx2 || dy>dy2 ||dz>dz2,
dx =e[[2,1]]-e[[1,1]]+If[dx<dx2,0, If[e[[2,1]]>e[[1,1]],-2π,+2π]];
dy =e[[2,2]]-e[[1,2]]+If[dy<dy2,0, If[e[[2,2]]>e[[1,2]],-2π,+2π]]; 
dz =e[[2,3]]-e[[1,3]]+If[dz<dz2,0, If[e[[2,3]]>e[[1,3]],-2π,+2π]];
{color1,Line[{e[[1]],e[[1]]+{dx,dy,dz}}],Line[{e[[2]],e[[2]]-{dx,dy,dz}}]},{If[-1===color2,color1,color2], Line[e]}]
]

toroidPt[e_,frac_]:=Module[{dx,dy,dx2,dy2,dz,dz2,dist,pt},
dx = Abs[e[[2,1]]-e[[1,1]]];
dy = Abs[e[[2,2]]-e[[1,2]]];
dz = Abs[e[[2,3]]-e[[1,3]]];
dx2 =e[[2,1]]-e[[1,1]]+If[dx<2π- dx,0, If[e[[2,1]]>e[[1,1]],-2π,+2π]];
dy2 =e[[2,2]]-e[[1,2]]+If[dy<2π- dy ,0, If[e[[2,2]]>e[[1,2]],-2π,+2π]];
dz2 =e[[2,3]]-e[[1,3]]+If[dz<2π- dz ,0, If[e[[2,3]]>e[[1,3]],-2π,+2π]];
dist = Sqrt[dx^2+dy^2+dz^2];
If[dist==0,pt=e[[1]],
pt=e[[1]]+frac{dx2,dy2,dz2};
pt[[1]] =wrapto0to2π[pt[[1]]];
pt[[2]] =wrapto0to2π[pt[[2]]];
pt[[3]] =wrapto0to2π[pt[[3]]];
];
pt ]

### [Input] (init)
jointAngle2Origin[{Theta1_,Theta2_,Theta3_}]:=Module[{o1,o2,o3},
o1= {Cos[Theta1],Sin[Theta1],1};
o2= o1+{Cos[Theta1]Cos[Theta2],Sin[Theta1]Cos[Theta2],Sin[Theta2]};
o3= o2+{Cos[Theta1]Cos[Theta2]Cos[Theta3]+Sin[Theta1]Sin[Theta3],Sin[Theta1]Cos[Theta2]Cos[Theta3]-Cos[Theta1]Sin[Theta3],Cos[Theta3]Sin[Theta2]};
Return[{o1,o2,o3}]
]

### [Input] (init)
detCollision[{o1_,o2_,o3_},pObs3_,obsRad_,widtha_]:=(
        pointsegdis2[{{{0,0,1},o1},pObs3}]<obsRad+widtha  (*link 1*)
||pointsegdis2[{{o1 ,o2},pObs3}]<obsRad+widtha  (*link 2*)
||pointsegdis2[{{o2,o3},pObs3}]<obsRad+widtha  (*link 3*)
||pointsegdis2[{{{0,0,0} ,{0,0,1+2widtha}},pObs3}]<obsRad+2*widtha  (*link 0 (base)*))

### [Text]
The goal of robot motion planning is to find a continuous path from an initial configuration to a goal configuration that is collision free. A configuration is a complete specification of every point of the robot. This Demonstration uses a three-link robot with three rotational joints that can each rotate from 0 to 2π. The joints can each rotate independently either clockwise or counterclockwise. Obstacles in the robot's workspace map to obstacle regions in a 3D configuration space. The robot's joint angles are specified by Subscript[Theta, 1], Subscript[Theta, 2] and Subscript[Theta, 3]. You can adjust the two obstacle positions in 3D. The "restart" button removes all the sampled configurations, and the "new goal" button randomly assigns a new goal position.

### [Text]
\<Changing the obstacle positions requires rebuilding the roadmap. Longer radius values require more computation but result in a denser roadmap and shorter paths.\>

### [Text]
\<PRM was developed in 1996 by Lydia Kavraki et al.[1]. PRMs generate a roadmap that can be reused for subsequent motion-planning queries. PRM was designed for high-dimension configuration spaces (dimensions of 5 or more), but this Demonstration uses three dimensions for ease of visualization.\>
