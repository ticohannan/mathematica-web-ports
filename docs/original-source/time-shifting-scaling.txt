### [Subsection]
Details & Citations<<PaneSelectorBox>>

### [Text]
Signal time shift and scaling are core concepts in a signals and systems class[1]. The following describes how the signal transformation variables (a,b,T) affect the input signal x(t).

### [Text]
The time-scaling factor a is analogous to "play-back speed." When a=2, the signal is replayed at two times the speed and so takes half as long. When a=1/4, the signal is replayed at one-quarter the speed and so takes four times as long. When |a|<1, the signal is expanded. When |a| >1, the signal is compressed.

### [Text]
The time-shifting factor b is the time delay. The input signal x(t-b) begins playing b seconds after the signal x(t). When b>0, the signal is shifted right on the x axis. When b<0, the signal is shifted left on the x axis.

### [Text]
When the function has both time-scaling and time-shifting factors, the output is x(a t-b)=x(a(t-T)), where T=b/a.

### [Text]
You can display the input signal x(t), the output signal y(t)=x(a t-b)=x(a(t-T)), and two intermediate signals z(t)=x(t-b) and w(t)=x(a t). For an overview of signal transformations, see[2].
