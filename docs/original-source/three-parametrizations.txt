findRollPitchYaw[R_]:=Module[{Alpha,Beta,Gamma},
(*Given a 3x3 rotation matrix R, finds the three rotations that generate R:
first a yaw about Subscript[x, 0] through an angle Alpha, second a pitch about Subscript[y, 0] by an angle Beta,and third a roll about Subscript[z, 0] by an angle Gamma (only returns one solution).

rotZYX[Gamma,Beta,Alpha]=(\[NoBreak]<<Grid:Cos[Beta] Cos[Gamma]Cos[Gamma] Sin[Alpha] Sin[Beta]-Cos[Alpha] Sin[Gamma]Cos[Alpha] Cos[Gamma] Sin[Beta]+Sin[Alpha] Sin[Gamma] | Cos[Beta] Sin[Gamma]Cos[Alpha] Cos[Gamma]+Sin[Alpha] Sin[Beta] Sin[Gamma]-Cos[Gamma] Sin[Alpha]+Cos[Alpha] Sin[Beta] Sin[Gamma] | -Sin[Beta]Cos[Beta] Sin[Alpha]Cos[Alpha] Cos[Beta]>>\[NoBreak])=(\[NoBreak]<<Grid:r11r12r13 | r21r22r23 | r31r32r33>>\[NoBreak])*)
If[ R[[3,2]]!=0||R[[3,3]]!=0,
Beta = ArcTan[Sqrt[1-R[[3,1]]^2],-R[[3,1]]];
Alpha=ArcTan[R[[3,3]],R[[3,2]]];
Gamma=ArcTan[R[[1,1]],R[[2,1]]];
, (*both zero, thus Beta is π/2 or -π/2*)
(*(\[NoBreak]<<Grid:Cos[Gamma]-Cos[Alpha] Sin[Gamma]Sin[Alpha] Sin[Gamma] | Sin[Gamma]Cos[Alpha] Cos[Gamma]-Cos[Gamma] Sin[Alpha] | 0Sin[Alpha]Cos[Alpha]>>\[NoBreak])=(\[NoBreak]<<Grid:r11r12r13 | r21r22r23 | r31r32r33>>\[NoBreak])*)
Beta = π/2;
Alpha=ArcTan[R[[3,3]],R[[3,2]]];
Gamma=ArcTan[R[[1,1]],R[[2,1]]];
];
Round[Chop[{Alpha,Beta,Gamma},10^-6],0.001]
]

findZYZEuler[R_]:=Module[{Theta1,Phi1,Psi1},
(*Given a 3x3 rotation matrix R, finds the three rotations that generate R using the ZYZ convention,which specifies the orientation of frame Subscript[o, 1]Subscript[x, 1]Subscript[y, 1]Subscript[z, 1] by three successive rotations. The first rotates about the z axis by the angle Phi. Next we rotate about the current y axis by the angle Theta. Finally, we rotate about the current z axis by the angle Psi.

findAxisAngle[R_]:=Module[{Theta,k},(*converts rotation matrix R into a rotation of Theta about axis k. R is a 3x3 rotation matrix, -π<=Theta<=π, and k is a 3x1 unit vector*)
Theta = ArcCos[(R[[1,1]]+R[[2,2]]+R[[3,3]]-1)/(2)];
k=If[ Sin[Theta]!= 0,
Flatten[(1)/(2 Sin[Theta ])(\[NoBreak]<<Grid:R[[3,2]]-R[[2,3]] | R[[1,3]]-R[[3,1]] | R[[2,1]]-R[[1,2]]>>\[NoBreak])],{1,0,0}];
Round[Chop[{Theta,k},10^-7],0.001]
]

This Demonstration shows three parametrizations to describe rotations between a fixed coordinate frame Subscript[o, 0]Subscript[x, 0]Subscript[y, 0]Subscript[z, 0] and a rotated frame Subscript[o, 1]Subscript[x, 1]Subscript[y, 1]Subscript[z, 1]. 

### [DetailNotes]
The first parametrization uses Euler angles. There are many Euler angle conventions. This Demonstration uses the ZYZ convention, which specifies the orientation of frame Subscript[o, 1]Subscript[x, 1]Subscript[y, 1]Subscript[z, 1] by three successive rotations. The first rotates about the z axis by the angle Phi. Next, we rotate about the current y axis by the angle Theta. Finally, we rotate about the current z axis by the angle Psi.

### [DetailNotes]
The composite rotation, using the shorthand convention of Subscript[s, Theta] for sin Theta and Subscript[c, Theta] for cos Theta, is

Euler's rotation theorem states that any combination of rotations of a rigid body, such that a point in the rigid body remains fixed, is equivalent to a single rotation about some axis that runs through the fixed point.
