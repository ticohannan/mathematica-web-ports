### [Title]
Shortest Path for Forward and Reverse Motion of a Car

### [Section]
Caption<<PaneSelectorBox>>

### [Text]
This Demonstration shows the shortest paths for a car in forward and reverse motion, with a minimum turning radius Subscript[r, min]. Use the locators to change the start and goal positions and orientations. A car with both forward and reverse gears is often called a Reeds\[Dash]Shepp car, while one with only a forward gear is a Dubins car, in honor of the mathematicians who first studied these problems.

(*
Implementation of the optimal path formulas given in the following paper:
"\<OPTIMAL PATHS FOR A CAR THAT GOES BOTH FORWARDS AND BACKWARDS\>"
J. A. REEDS AND L. A. SHEPP
notes: there are some typos in the formulas given in the paper;
some formulas have been adapted (cf http://msl.cs.uiuc.edu/~lavalle/cs326a/rs.c)
Each of the 12 functions (each representing 4 of the 48 possible words)
have 3 arguments x, y and Phi, the goal position and angle (in degrees) of the
object given it starts at position (0, 0) and angle 0, and returns the
corresponding path (if it exists) as a list of PathElements (or an empty list).
(Actually there are less than 48 possible words but this code is not optimized.)
Converted from the Python at:
https://github.com/nathanlct/reeds-shepp-curves/blob/master/reeds_shepp.py
*)
{sLEFT,sSTRAIGHT,sRIGHT}={-1,0,1}; (*Constants for turning*)

{gFORWARD,gBACKWARD} = {1,-1}; (*Constants for movement direction*)

### [Input] (init)
getPos[path_,pose_, minRadius_:1, progress_:0]:=
(*Extracts the pose of a car that started at position & orientation pose, and followed progress % of path (with minimum turning radius minRadius) *)
(*also returns Alpha, the wheel angle for the front wheels *)
Module[{i,gear,steer,param,pos,Theta,angS,angE,distTrav,distSoFar,breakHere,sectionParam,Alpha},
distTrav = progress*pathLength[path];
distSoFar=0;
pos = pose[[1;;2]];Theta = pose[[3]];
breakHere = False;
Alpha=0;
i=0;
While[i<Length[path],i=i+1;
param = path[[i,1]];steer = path[[i,2]]; gear =path[[i,3]];
If[distTrav<distSoFar+param, breakHere = True; sectionParam = distTrav-distSoFar,sectionParam = param];
If[steer==-1,(*Left*)
angS = Theta-π/2;
Alpha=minRadius;
angE = angS+gear*sectionParam;
pos = pos+minRadius*{Cos[angE]-Cos[angS],Sin[angE]-Sin[angS]};
 Theta=Theta+gear*sectionParam;
,
If[steer==1,(*Right*)
angS = Theta+π/2; 
Alpha=-minRadius;
angE = angS-gear*sectionParam;
pos = pos+minRadius*{Cos[angE]-Cos[angS],Sin[angE]-Sin[angS]};
 Theta=Theta-gear*sectionParam;
,
If[steer==0,(*Straight*)
Alpha=0;
pos = pos+gear*minRadius*sectionParam{Cos[Theta],Sin[Theta]};
]]];
If[breakHere, Break[]];
distSoFar = distSoFar+param;
];(*End while loop*)
{pos,Theta,Alpha}
]

### [Input] (init)
changeOfBasisR[p1_,p2_,minRadius_:1]:=Module[{xn,yn,Thetan, Theta1, dx,dy},
(*Given p1 = {x1,y1,Theta1} and p2 = {x2,y2,Theta2} represented in a coordinate system with origin {0,0} and rotation 0 (in radians) with minimum turning radiusminRadius, return the position and orientation of p2 in the coordinate system in which origin is {x1,y1} and rotation Theta2-Theta1 in radians, and minRadius is 1.*)
Theta1 =p1[[3]];
dx = (p2[[1]]-p1[[1]])/(minRadius);
dy =( p2[[2]]-p1[[2]])/(minRadius);
xn = dx*Cos[Theta1]+dy*Sin[Theta1];
yn = -dx*Sin[Theta1]+dy*Cos[Theta1];
Thetan = p2[[3]]-p1[[3]];
{xn,yn,Thetan}
]

### [Input] (init)
modπ[Theta_]:=Module[{Phi}, (*Returns the angle Phi = Theta mod (2π) such that -π <=Phi<= π. *)
Phi=Mod[Theta,2π];
If[ Phi<-π, Phi=Phi+2π];
If[ Phi> π, Phi=Phi-2π];
Phi
]

### [Input] (init)
mod2π[Theta_]:=Module[{Phi}, (*Returns the angle Phi = Theta mod (2π) such that 0 <=Phi<= 2π. *)
Phi=Mod[Theta,2π];
If[ Phi<0, Phi=Phi+2π];
Phi
]

{r,Theta}]

### [Input] (init)
getAllDubinsPaths[start_,end_,minRadius_:1]:=Module[{pathFns,paths,x,y,Theta},
(*    Return a list of all the paths from start to end generated by the
    6 functions *)
pathFns = {dLSL,dLSR,dRSR,dRSL,dLRL,dRLR};
paths={};
(* get coordinates of end in the set of axis where start is (0,0,0) *)
{x,y,Theta}=changeOfBasisR[start,end,minRadius];
(* get the four variants for each path type, cf article*)
Table[AppendTo[paths,getPath[x,y,Theta]];,{getPath,pathFns}];
(*remove path elements that have parameter 0*)
paths=DeleteCases[paths,{0,_,_},2];
(* remove empty paths*)
paths = DeleteCases[paths,{},2];
paths (*Return*) 
]

### [Input] (init)
getAllPaths[start_,end_,minRadius_:1]:=Module[{pathFns,paths,x,y,Theta},
(* Return a list of all the paths from start to end generated by the 12 functions and their variants *)
pathFns = {path1,path2,path3,path4,path5,path6,path7,path8,path9,path10,path11,path12};
paths={};
(* get coordinates of end in the set of axis where start is (0,0,0) *)
{x,y,Theta}=changeOfBasisR[start,end,minRadius];
(* get the four variants for each path type, cf article*)
Table[
AppendTo[paths,getPath[x,y,Theta]];
AppendTo[paths,timeflip[getPath[-x,y,-Theta]]];
AppendTo[paths,reflect[getPath[x,-y,-Theta]]];
AppendTo[paths,reflect[timeflip[getPath[-x,-y,Theta]]]];
,{getPath,pathFns}];
(*remove path elements that have parameter 0*)
paths=DeleteCases[paths,{0,_,_},2];
(* remove empty paths*)
paths = DeleteCases[paths,{},2];
paths (*Return*) 
]

### [Input] (init)
dLSL[x_,y_,Phi_]:=Module[{path,u,t,v},(*Formula: Dubins LSL *)
path={};
{u,t}=cart2Polar[x-Sin[Phi],y-1+Cos[Phi]];
t=mod2π[t];
v=mod2π[Phi-t];
AppendTo[path,createPathElement[{t,sLEFT,gFORWARD}]];
AppendTo[path,createPathElement[{u,sSTRAIGHT,gFORWARD}]];
AppendTo[path,createPathElement[{v,sLEFT,gFORWARD}]];
(*return*) N[ path]
]

AppendTo[path,createPathElement[{u,sSTRAIGHT,gFORWARD}]];

(*return*) N[ path]
]

### [Input] (init)
dLRL[x_,y_,Phi_]:=Module[{path,ξ,η,ρ,Theta,u,t,v,a},
    (*Dubins LRL is like Formula 8.3: CCC *)
path={};
ξ=x-Sin[Phi];
η=y-1+Cos[Phi];
{ρ,Theta}=cart2Polar[ξ,η];
If[ ρ<=4,a=ArcCos[ρ/4];
	t=mod2π[Theta+π/2+a];
	u=mod2π[(π+2*a)];
	v=mod2π[Phi-t+u];
AppendTo[path,createPathElement[{t,sLEFT,gFORWARD}]];
	AppendTo[path,createPathElement[{u,sRIGHT,gFORWARD}]];
	AppendTo[path,createPathElement[{v,sLEFT,gFORWARD}]];];
(*return*) N[ path]]

### [Text]
This Demonstration is based on a simplified mathematical model of a car that can move in the x-y plane[1]. The car's coordinates are the center of the rear axle (x,y) and its orientation Theta. The car cannot move sideways because the rear wheels would have to slide instead of roll. The model stipulates that the car has a maximum steering angle that translates into a minimum turning radius Subscript[r, min]. Circles showing the minimum turning radius are drawn as thin gray lines tangent to the curved sections of the path.

### [Text]
The changes of coordinates with velocity v are given by

### [Text]
dx=v cos Theta,

### [Text]
dy=v sin Theta,

### [Text]
dTheta=u,

### [Text]
with the steering constraint limits u∈[-1/Subscript[r, min],1/Subscript[r, min]]. The task is to minimize the length of the curve traced out by the center of the rear axle as it moves from the start to the goal[2]. That path is the bounded-curvature shortest path. Reeds and Shepp proved that the shortest path consists of no more than five segments, where in each segment u is either -1/Subscript[r, min], 0 or 1/Subscript[r, min] and the car is moving either forward or backward[3]. The optimal path is one of 48 different path types. The Reeds\[Dash]Shepp path can be used as a metric for the (x,y,Theta) configuration of a car. The distance does not change if you swap the start and goal positions.

### [Text]
\<The Dubins car has only six possible path types[3]. Because it can only move forward, the Dubins path is never shorter than the Reeds\[Dash]Shepp path. The Dubins path is not a metric, and often the distance changes if the start and goal positions are swapped[4].\>
