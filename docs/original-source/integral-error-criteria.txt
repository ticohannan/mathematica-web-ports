
### [Title]
Integral Error Criteria for Controller Tuning

### [Section]
Caption<<PaneSelectorBox>>

### [Text]
Consider the closed loop shown in Figure 10.8 in[1], where Subscript[G, p]=(1)/(5 s+1), Subscript[G, v]=(1)/(2 s+1), Subscript[G, m]=(1)/(s+1), Subscript[K, m]=1, and Subscript[G, c]=Subscript[K, c](1+(1)/(5 s)).

### [Text]
Here we consider a proportional-integral controller. Set the value of the control gain Subscript[K, c]; the integral time is fixed (Subscript[τ, I]=5).

### [Text]
The closed-loop transfer function for step point changes is given by G=(Y)/(Subscript[Y, sp])=(Subscript[K, c]  (1+s))/(Subscript[K, c]+5 s (1+3 s+2 s^2)) (if there is no disturbance).

### [Text]
When a step in the set point is applied (i.e. Subscript[Y, sp]=(1)/(s)), the response y(t) is plotted and values of the three integral errors are given (see Snapshot 1).

### [Text]
These integral errors (all truncated at t=5000 in the calculation shown here) are defined by:

### [Text]
IAE=Subscript[\[Integral],0]^∞\[LeftBracketingBar]e(t)\[RightBracketingBar]dt (the integral of the absolute value of the error indicated by the gray area shown in the response versus time plot),

### [Text]
ISE=Subscript[\[Integral],0]^∞(e(t))^2dt (the integral of the squared error),

### [Text]
and ITAE=Subscript[\[Integral],0]^∞t \[LeftBracketingBar]e(t)\[RightBracketingBar]dt (the integral of the time-weighted absolute error).

### [Text]
In addition, the Demonstration performs controller tuning by computing the values of Subscript[K, c] that minimize the integral errors (see Snapshots 2\[Dash]4). These are shown by blue dots.

### [Text]
A frequency analysis shows that sustained oscillations (shown in Snapshot 5) take place when Subscript[K, c]=7.5 and Omega=(Sqrt[2])/(2).
