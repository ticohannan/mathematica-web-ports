### [Title]
Probabilistic Roadmap Method for Robot Arm

### [Section]
Caption<<PaneSelectorBox>>

### [Text]
\<This Demonstration uses the Probabilistic Roadmap Method (PRM) to plan a motion path for a two-link robot that avoids collisions with a blue sphere and an orange sphere. First, click "add 100 vertices" to randomly sample configurations and calculate if they collide with obstacles (red points) or are safe (green points). Next, select "radius" value to try to connect safe vertices less than radius distance apart into a roadmap. If a path from the initial to goal configuration is found, it can be traversed with the "progress" slider. Although the PRM does not need to calculate the configuration space obstacles, you can make them visible with a checkbox.\>

### [Input] (init)
ptInPoly[poly_,pt_]:=
			(* translate poly such that pt becomes origin *)
			poly//#-pt&/@#&//
			(* pt is inside if adjacent vertex vector pair angles are all positive or all negative *)
			{#,RotateLeft@#}&//Transpose//angtest@@#&/@#&//Equal@@#&

### [Input] (init)
ptInPolys[polys_,pt_]:=Or@@(ptInPoly[#,pt]&/@polys)

### [Input] (init)
pathOK[ps_,pe_,polys_,delta_]:=Module[{dist,n,pt},
dist = Norm[ps-pe];
If[dist<= delta,
True,
n=Ceiling[dist/delta];
!Or@@Table[pt = ps+ (pe-ps)*(i)/(n+1);
ptInPolys[polys,pt]  ,{i,1,n}]]
]

### [Input] (init)
pathOKT[ps_,pe_,polys_,delta_]:=Module[{dist,n,pt,dx,dx2,dy,dy2},
(*Toroid assumption*)
dx = Abs[pe[[1]]-ps[[1]]];
dx2 =2π- dx;
dy = Abs[pe[[2]]-ps[[2]]];
dy2 =2π-dy ;

dx=pe[[1]]-ps[[1]]+If[dx<dx2,0, If[pe[[1]]>ps[[1]],-2π,+2π]];
dy=pe[[2]]-ps[[2]]+If[dy<dy2,0, If[pe[[2]]>ps[[2]],-2π,+2π]];

dist = Sqrt[dx^2+dy^2];
If[dist<= delta,
True,
n=Ceiling[dist/delta];
!Or@@Table[pt = ps+ {dx,dy}*(i)/(n+1);
If[pt[[1]]<0,pt[[1]]=pt[[1]]+2π];
If[pt[[1]]>2π,pt[[1]]=pt[[1]]-2π];
If[pt[[2]]<0,pt[[2]]=pt[[2]]+2π];
If[pt[[2]]>2π,pt[[2]]=pt[[2]]-2π];
ptInPolys[polys,pt]  ,{i,1,n}]]
]

### [Input] (init)
pathOKTrobot[ps_,pe_,pObs3_,obsRad_,widtha_,delta_]:=Module[{dist,n,pt,dx,dx2,dy,dy2},
(*Toroid assumption*)
dx = Abs[pe[[1]]-ps[[1]]];
dx2 =2π- dx;
dy = Abs[pe[[2]]-ps[[2]]];
dy2 =2π-dy ;

dx=pe[[1]]-ps[[1]]+If[dx<dx2,0, If[pe[[1]]>ps[[1]],-2π,+2π]];
dy=pe[[2]]-ps[[2]]+If[dy<dy2,0, If[pe[[2]]>ps[[2]],-2π,+2π]];

dist = Sqrt[dx^2+dy^2];
If[dist<= delta,
True,
n=Ceiling[dist/delta];
!Or@@Table[pt = ps+ {dx,dy}*(i)/(n+1);
If[pt[[1]]<0,pt[[1]]=pt[[1]]+2π];
If[pt[[1]]>2π,pt[[1]]=pt[[1]]-2π];
If[pt[[2]]<0,pt[[2]]=pt[[2]]+2π];
If[pt[[2]]>2π,pt[[2]]=pt[[2]]-2π];
detCollision[pt[[1]],pt[[2]],pObs3,obsRad,widtha]  ,{i,1,n}]]
]

### [Input] (init)

### [Input] (init)
myAstar[adjL_,verts_,si_,fi_]:=Module[{openSet,cameFrom,gScore,fScore,current,currentfscore,path,tentativegScore},
(*The set of discovered nodes that may need to be (re-)expanded.
Initially,only the start node is known.*)
openSet={si};
cameFrom  = ConstantArray[-1, Length[verts]]; (*For node n,cameFrom[n] is the node immediately preceding it on the cheapest path from start to n currently known.*)
gScore = ConstantArray[∞, Length[verts]]; (*For node n,gScore[n] is the cost of the cheapest path from start to n currently known.*)
gScore[[si]] = 0;
(*For node n,fScore[n]:=gScore[n]+h(n).*)
fScore= ConstantArray[∞, Length[verts]]; (*map with default value of Infinity*)
fScore[[si]]=toroidDist[verts[[si]] , verts[[fi]]];
While[Length[openSet]>0 (*&& ctr<10*),
(*current:=the node in openSet having the lowest fScore[] value*)
currentfscore = Min[fScore[[openSet]]];
current =openSet[[ First@@Position[fScore[[openSet]],currentfscore]]];

If[ current == fi,
path = {fi};While[First@path!=si,PrependTo[path,cameFrom[[First@path]]]];
Return[path]
];
openSet = DeleteCases[openSet,current];
Table[
tentativegScore = gScore[[current]]+toroidDist[verts[[current]],verts[[nbr]]];
If[tentativegScore< gScore[[nbr]],
                (*This path to neighbor is better than any previous one. Record it!*)
cameFrom[[nbr]]=current;
gScore[[nbr]]=tentativegScore;fScore[[nbr]]=gScore[[nbr]]+toroidDist[verts[[nbr]] , verts[[nbr]]];
If[ FreeQ[openSet,nbr],AppendTo[openSet,nbr]]];
,{nbr,adjL[[current]]}];
];	
Return[-1]  (*Failure*)
]

### [Input] (init)
toroidLine[e_,color1_:Blue,color2_:-1]:=Module[{dx,dx2,dy,dy2},
dx = Abs[e[[2,1]]-e[[1,1]]];
dx2 =2π- dx;
dy = Abs[e[[2,2]]-e[[1,2]]];
dy2 =2π- dy ;
If[dx>dx2 || dy>dy2,
dx =e[[2,1]]-e[[1,1]]+If[dx<dx2,0, If[e[[2,1]]>e[[1,1]],-2π,+2π]];
dy =e[[2,2]]-e[[1,2]]+If[dy<dy2,0, If[e[[2,2]]>e[[1,2]],-2π,+2π]]; {color1,Line[{e[[1]],e[[1]]+{dx,dy}}],Line[{e[[2]],e[[2]]-{dx,dy}}]},{If[-1===color2,color1,color2], Line[e]}]
]

### [Input] (init)
toroidPt[e_,frac_]:=Module[{dx,dy,dx2,dy2,dist,pt},
dx = Abs[e[[2,1]]-e[[1,1]]];
dy = Abs[e[[2,2]]-e[[1,2]]];
dx2 =e[[2,1]]-e[[1,1]]+If[dx<2π- dx,0, If[e[[2,1]]>e[[1,1]],-2π,+2π]];
dy2 =e[[2,2]]-e[[1,2]]+If[dy<2π- dy ,0, If[e[[2,2]]>e[[1,2]],-2π,+2π]];
dist =Sqrt[dx2^2+dy2^2];
If[dist==0,pt=e[[1]],
pt=e[[1]]+frac{dx2,dy2};
pt[[1]] =pt[[1]]+If[pt[[1]]>2π,-2π,If[pt[[1]]<0,2π,0]];
pt[[2]] =pt[[2]]+If[pt[[2]]>2π,-2π,If[pt[[2]]<0,2π,0]];
];
pt ]

### [Text]
The goal of robot motion planning is to find a continuous path from an initial configuration to a goal configuration that is collision free. A configuration is a complete specification of every point of the robot. This Demonstration uses a two-link robot with two rotational joints that can each rotate from 0 to 2π. The resulting configuration space can be represented as a toroid, and so wraps from 2π to 0 on the edges of the plot shown. Obstacles in the robot's workspace map to obstacle regions in the configuration space, but computing these regions is computationally expensive.

### [Text]
\<Changing the obstacle positions requires rebuilding the roadmap. Longer radius values require more computation but result in a denser roadmap and shorter paths.\>

### [Text]
\<PRM was developed in 1996 by Lydia Kavraki et al.[1]. PRMs generate a roadmap that can be reused for subsequent motion-planning queries. PRM was designed for high-dimension configuration spaces (dimensions of 5 or more), but this Demonstration uses two dimensions for ease of visualization.\>

### [Text]
[1] L. E. Kavraki, P. Svestka, J-C. Latombe and Mark H. Overmars. "Probabilistic Roadmaps for Path Planning in High-Dimensional Configuration Spaces." IEEE Transactions on Robotics and Automation, 12(4), 1996 pp. 566\[Dash]580. doi:10.1109/70.508439.
