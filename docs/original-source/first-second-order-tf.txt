
### [Title]
First- and Second-Order Transfer Functions

### [Section]
Caption<<PaneSelectorBox>>

### [Text]
This Demonstration plots the time-domain response of a system with a step input of unity. Select either a first-order plus dead time (FOPDT) model or a second-order plus dead time (SOPDT) model. Set the time constant τ to change how quickly the system reaches a new steady state, the process gain K to change how aggressively the system responds to the unity step input and the dead time Theta that delays the system response by a value of Theta. For the second-order process, change the damping coefficient ζ with a slider. The damping coefficient is a measure of the magnitude of damping, which affects the degree of oscillation in the response. Dimensionless time is used.

### [Subsection]
Details & Citations<<PaneSelectorBox>>

### [Text]
\<The general first-order transfer function in the Laplace domain is:\>

### [Text]
G(s)=(Y(s))/(U(s))=(K e^(-Theta s))/(τ s+1),

### [Text]
where K is the process gain, τ is the time constant, Theta is the system dead time or lag and s is a Laplace variable. The process gain is the ratio of the output response to the input (unit step for this Demonstration), the time constant determines how quickly the process responds or how rapidly the output changes and the dead time delays the system response by the amount Theta.

### [Text]
\<This Demonstration converts from the Laplace domain to the time domain for a step-response input. For a first-order transfer function, the time-domain response is:\>

### [Text]
y(t)=K (1-e^(-(t-Theta)/τ)).

### [Text]
\<The general second-order transfer function in the Laplace domain is:\>

### [Text]
G(s)=(K e^(-Theta s))/(τ^2 s^2+2 ζ τ s+1),

### [Text]
where ζ is the (dimensionless) damping coefficient.

### [Text]
\<For a step-response input, the time-domain response for various damping coefficients are:\>

### [Text]
Overdamped (ζ>1):

### [Text]
y(t)=K (1-e^(-ζ (t-Theta)/τ) (cosh [Sqrt[ζ^2-1] (t-Theta)/τ]+(ζ)/(Sqrt[ζ^2-1]) sinh[Sqrt[ζ^2-1] (t-Theta)/τ])).

### [Text]
Critically damped (ζ=1):

### [Text]
y(t)=K (1+(1-(t-Theta)/(τ)) e^(-(t-Theta)/τ)).

### [Text]
Underdamped (ζ<1):

### [Text]
y(t)=K (1-e^(-ζ (t-Theta)/τ) (cos[Sqrt[1-ζ^2] (t-Theta)/τ]+(ζ)/(Sqrt[1-ζ^2]) sin[Sqrt[1-ζ^2] (t-Theta)/τ])).
