### [Title]
Manipulability Ellipsoid of a Robot Arm

### [Section]
Caption<<PaneSelectorBox>>

### [Text]
\<Manipulability of a robot is the capacity to change the end effector's position as a function of the joint configuration[1]. A larger manipulability measure indicates a greater range of possible motions at that configuration. The manipulability measure reduces to zero when the robot is in a singular configuration and cannot generate velocities in at least one direction.\>

### [Text]
\<The manipulability ellipsoid includes all possible velocities normalized for a unit input at a given robot configuration. These velocities are calculated using the robot\[CloseCurlyQuote]s velocity Jacobian.\>

### [Text]
\<In this Demonstration, you can adjust a three-link elbow manipulator\[CloseCurlyQuote]s configuration to see how the joint configuration affects the manipulability. For singular configurations, the Jacobian loses rank, causing the manipulability ellipsoid to lose dimensions to either an ellipse or a line.\>

### [Text]
\<Calculating the manipulability requires defining the robot configuration in terms of joint angles (forward kinematics) and then calculating how joint velocities generate velocity of the end effector (velocity kinematics).\>

### [Text]
The configuration is defined using transformation matrices derived using the Denavit\[Dash]Hartenberg convention. The three joints of the elbow manipulator allow three positional degrees of freedom, and the location (origin) of each joint is determined from these transformation matrices. These origins are combined with the axes of rotation from the same transformation matrices to develop the velocity Jacobian, which relates the end effector velocity to the rate of change in the joint positions. The velocity Jacobian J used in this Demonstration is given in[2, eq. 4.98, p. 144]. It is a function of the rotational position of each of the three joints, described by the variables Subscript[Theta, 1], Subscript[Theta, 2], and Subscript[Theta, 3].

### [Text]
The velocity Jacobian is J=(\[NoBreak]<<Grid:(-Subscript[r, 2] Subscript[c, 2]-Subscript[r, 3] Subscript[c, 23]) Subscript[s, 1]-Subscript[r, 2] Subscript[c, 1] Subscript[s, 2]-Subscript[r, 3] Subscript[c, 1] Subscript[s, 23]-Subscript[r, 3] Subscript[c, 1] Subscript[s, 23] | Subscript[c, 1] (Subscript[r, 2] Subscript[c, 2]+Subscript[r, 3] Subscript[c, 23])-Subscript[r, 2] Subscript[s, 1] Subscript[s, 2]-Subscript[r, 3] Subscript[s, 1] Subscript[s, 23]-Subscript[r, 3] Subscript[s, 1] Subscript[s, 23] | 0Subscript[r, 2] Subscript[c, 2]+Subscript[r, 3] Subscript[c, 23]Subscript[r, 3] Subscript[c, 23]>>\[NoBreak]),

### [Text]
where Subscript[s, 1] is shorthand for sin(Subscript[Theta, 1]), Subscript[c, 23] is shorthand for cos(Subscript[Theta, 2]+Subscript[Theta, 3]), and so on, and the lengths of links 2 and 3 are Subscript[r, 2] and Subscript[r, 3].

### [Text]
The manipulability measure is calculated as the product of the diagonal elements Subscript[σ, i] in the \[CapitalSigma] matrix that results from the singular value decomposition of the velocity Jacobian, μ=<<UnderoverscriptBox>>Subscript[σ, i]. It may also be defined relative to the determinant of the Jacobian as μ=Sqrt[det(J J^T)]. From this definition, it is clear that μ=0 when the determinant of the Jacobian is zero. This occurs when the manipulator is in a singular configuration. The determinant of the Jacobian is J=-Subscript[r, 2] Subscript[r, 3] (Subscript[r, 2] Subscript[c, 2]+Subscript[r, 2] Subscript[c, 23]) Subscript[s, 3]. When the elbow manipulator is in the configuration[Subscript[Theta, 1], Subscript[Theta, 2], k π], k∈\[DoubleStruckCapitalZ], the Jacobian has rank 2, and the three-dimensional ellipsoid flattens to a two-dimensional ellipse. At the configuration[Subscript[Theta, 1],π/2+ k π, j π], (j,k)∈\[DoubleStruckCapitalZ]^2, the Jacobian has rank 1, and the ellipsoid collapses to a line. Snapshot 1 gives a three-dimensional ellipse, snapshot 2 a two-dimensional ellipse, and snapshot 3 a one-dimensional ellipse.
