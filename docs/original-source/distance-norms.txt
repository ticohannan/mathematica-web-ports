### [Title]
Distance Norms in Robot Workspace and Phase Space

### [Section]
Caption<<PaneSelectorBox>>

### [Text]
This Demonstration shows the area within the distance d of a two-link planar-arm robot with configuration (Subscript[Theta, 1],Subscript[Theta, 2]). The distance d is measured in the Subscript[L, 1], Subscript[L, 2], Subscript[L, 3] or Subscript[L, ∞] norm, with the norm applied either in the workspace or the phase space of the robot. You can change the norm type, the length of the first arm joint and the angles of the two arm joints.

### [Text]
\<The measurement of distance between two configurations of the same robot is necessary for many robot motion planners, such as probabilistic road-map methods and rapidly expanding random trees.\>

### [Text]
The vector norm |xSubscript[|, p] for p=1,2,\[Ellipsis] is defined as |xSubscript[|, p]=<<RadicalBox>>.

### [Text]
The special case for p=∞ is defined as |xSubscript[|, ∞]=Subscript[max, i]|Subscript[x, i]|.

### [Text]
If a given robot configuration (Subscript[Theta, 1]^*,Subscript[Theta, 2]^*) places the tip of the robot at position (Subscript[x, r],Subscript[y, r]), the workspace norms are Subscript[L, 1]=|Subscript[x, r]-x|+|Subscript[y, r]-y|, Subscript[L, 2]=Sqrt[(Subscript[x, r]-x)^2+(Subscript[y, r]-y)^2], Subscript[L, 3]=<<RadicalBox>> and Subscript[L, ∞]=max(|Subscript[x, r]-x|,|Subscript[y, r]-y| ).

### [Text]
It is trivial to compute the distance using norms in the workspace; however, these distances are often misleading. The arm's workspace is the unit disk, but the Subscript[L, ∞]<1/2 workspace norm shown in Snapshot 1 includes an area inaccessible to the robot arm.

### [Text]
It is more correct to calculate the set of configurations with distance less than d in the phase space of the robot and then map this set into the workspace. These norms are Subscript[L, 1]=|Subscript[Theta, 1]^*-Subscript[Theta, 1]| +|Subscript[Theta, 2]^*-Subscript[Theta, 2]|, Subscript[L, 2]=Sqrt[(Subscript[Theta, 1]^*-Subscript[Theta, 1])^2+(Subscript[Theta, 2]^*-Subscript[Theta, 2])^2], Subscript[L, 3]=<<RadicalBox>> and Subscript[L, ∞]=max(|Subscript[Theta, 1]^*-Subscript[Theta, 1] ,|Subscript[Theta, 2]^*-Subscript[Theta, 2]| ). The mapping into the workspace is performed using Mathematica's ParametricPlot command.

### [Text]
Notice that lower-order norms are contained by higher-order norms: Subscript[L, 1]\[SubsetEqual]Subscript[L, 2]\[SubsetEqual]Subscript[L, 3]\[SubsetEqual]Subscript[L, ∞].
