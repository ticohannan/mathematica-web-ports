### [Title]
Unit Balls for Different p-Norms in 2D and 3D

### [Section]
Caption<<PaneSelectorBox>>

### [Text]
This Demonstration shows the set of points within distance 1 from the origin in 2D and in 3D. The distance is measured using different p-norms, which are standard norms for finite-dimensional spaces. This set of points is called the unit ball.

### [Section]
Initialization Code<<PaneSelectorBox>>

### [Input] (init)
myNorm[{x_,y_,z_},p_]:=(Abs[x]^p+Abs[y]^p+Abs[z]^p)^1/p

### [Input] (init)
myNorm2[{x_,y_},p_]:=(Abs[x]^p+Abs[y]^p)^1/p

### [Text]
In mathematics, a norm is the length (or size) of a vector. A p-norm is a norm on a finite-dimensional space of dimension N defined as

### [Text]
Subscript[\[LeftDoubleBracketingBar]u\[RightDoubleBracketingBar], p]=(<<UnderoverscriptBox>>\[LeftBracketingBar]Subscript[u, n]\[RightBracketingBar]^p)^1/p.

### [Text]
This Demonstration shows sets of unit-norm vectors u for different p-norms.

### [Text]
The norm for p=1 is the sum of the distances a 3D computer numerical control (CNC) mill would have to move in the x, y and z directions. In 3D the unit ball is an octahedron, and in 2D it is a square with corners at (1,0),(0,1),(-1,0),(0,-1);

### [Text]
Subscript[\[LeftDoubleBracketingBar]u\[RightDoubleBracketingBar], 1]=\[LeftBracketingBar]x\[RightBracketingBar]+\[LeftBracketingBar]y\[RightBracketingBar]+\[LeftBracketingBar]z\[RightBracketingBar].

### [Text]
The norm for p=2 is the usual Euclidean square norm obtained using the Pythagorean theorem. In 3D the unit ball is a sphere, and in 2D it is a circle with radius 1;

### [Text]
||uSubscript[||, 2]=Sqrt[|x|^2+|y|^2+|z|^2].

### [Text]
The norm for p=∞ is simply the maximum over x, y and z. This is proportional to the time a CNC mill would take to reach a goal if all axes can move simultaneously with the same top speed. In 3D the unit ball is a unit cube, and in 2D it is a square with corners at (1,1),(-1,1),(-1,-1),(1,-1);

### [Text]
Subscript[\[LeftDoubleBracketingBar]u\[RightDoubleBracketingBar], ∞]=max(\[LeftBracketingBar]x\[RightBracketingBar],\[LeftBracketingBar]y\[RightBracketingBar],\[LeftBracketingBar]z\[RightBracketingBar]).

### [Text]
The norms for p<1 are uncommon, but represent where there is a penalty for moving in more than one cardinal direction. This often occurs when trying to accomplish multiple objectives with a fixed budget. For example, flying cars have existed since 1935, but car-airplane hybrids are usually both poorly performing automobiles and ungainly fliers. In 3D and 2D the unit balls are star shapes with points along the coordinate axes. The following metric might represent these tradeoffs if x represents ability as a car, y ability as an airplane and z ability as a boat;

### [Text]
Subscript[\[LeftDoubleBracketingBar]u\[RightDoubleBracketingBar], 1/2]=(Sqrt[\[LeftBracketingBar]x\[RightBracketingBar]]+Sqrt[\[LeftBracketingBar]y\[RightBracketingBar]]+Sqrt[\[LeftBracketingBar]z\[RightBracketingBar]])^2.	

### [Text]
\<In 2D, this Demonstration shows the norm functions as orange 3D shapes filled with blue water up to distance 1 from the origin. When this is viewed from above, the area filled with water is the 2D unit ball.\>

### [Text]
In 3D, this Demonstration shows unit balls for the selected norm value. The unit ball is distance 1 from the origin, according to the selected p-norm.

### [Text]
The built-in Wolfram Language function Norm can be used to build similar plots, but it requires that p\[GreaterSlantEqual]1.

### [Text]
For vectors, Norm[v,p] is Total[Abs[v]^p]^(1/p).

### [Text]
For vectors, Norm[v,Infinity] is the ∞\[Hyphen]norm given by Max[Abs[v]].
