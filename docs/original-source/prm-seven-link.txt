### [Title]
\<Probabilistic Roadmap Method with Seven-Link Articulated Robot\>

### [Section]
Caption<<PaneSelectorBox>>

### [Text]
\<This Demonstration challenges you to move the seven-link robot (in brown) to match a goal configuration (in green) with the minimum number of collisions. Drag the locators to move the robot while avoiding collisions with the blue obstacles. This example was used in 1995 to introduce the probabilistic roadmap method (PRM), a robot motion-planning technique. Selecting "relative" movement changes the angle of one robot link at a time, and "absolute" rotates all subsequent links.\>

### [Input] (init)
(*The parametric equation of the line containing the points a and b is a+Gamma (b-a), where 0<=Gamma<=1 for points between a and b. The value of Gamma is given by*)
Gamma[{a_,b_}][p_]:=((a-p).(a-b))/((a-b).(a-b))
(*for p on the line. For p not on the line, Gamma gives the closest point on the line.*)

### [Input] (init)
(* Two lines, Subscript[L, 1 ]containing the points a and b with line Subscript[L, 2] containing the points c and d, intersect at a point \[DoubleLongLeftRightArrow] \[LeftBracketingBar]{a-b,c-d}\[RightBracketingBar]!=0. Compute the intersection point:*)
lineIntersectionPoint[{{a_,b_},{c_,d_}}]:=(Det[{a,b}] (c-d)-Det[{c,d}] (a-b))/(Det[{a-b,c-d}])

### [Input] (init)
(*Use \[LeftBracketingBar]{a-b,c-d}\[RightBracketingBar]!=0 along with the condition 0<=λ<=1 to determine whether two segments intersect:*)
segmentIntersectionQ[{p1:{a_,b_},p2:{c_,d_}}]:=
If[Det[{a-b,c-d}]==0,False,
Module[{p=lineIntersectionPoint[{p1,p2}]},0<=Gamma[p1][p]<=1&&0<=Gamma[p2][p]<=1]]

### [Input] (init)
lineIntersectionPoint[{a_,b_},{c_,d_}]:=(Det[{a,b}] (c-d)-Det[{c,d}] (a-b))/Det[{a-b,c-d}]

### [Input] (init)
angDiff[a_,b_] := If[a==b,0,ArcTan[Cos[a-b],Sin[a-b]]]

maxY=884,

{3.35, 1.3,0.16,0.55,-0.01,5.34,5.57}(*c3*),
{5.23,5.76, 6.08,5.22,4.78,5.94,0.22}(*c4*),
{3.37,1.26, 0.22,5.22,0.62,0.22,5.61}(*c5*),
{ 5.8,0.5,5.75,5.4,5.5 ,0.6,6.3}(*c6*),
{ 5.1,5.89,6.23,6.29,5.78,5.4,5.73}(*c7*),
{ 3.79,0.67,0.10,5.63, 0.6, 0.45,1.31}(*c8*),{ 3.63, 5.76,1.02, 0.13, 1.27, 5.47, 6.20} (*initial position of robot*)},

},
tg=Accumulate[goals[[goal]]];
og=Accumulate[Prepend[Table[linklen{Cos[tg[[i]]],Sin[tg[[i]]]},{i,1,7}],origin]];
worstError = Max[Norm/@(og-Prepend[locOld,origin])];
If[worstError<20 && !isCollide,success=True];
For[i==1,i<= 7,i++,
If[locOld[[i]]!=loc[[i]],
prev =If[i==1,origin, loc[[i-1]]];
Theta = ArcTan[ loc[[i,1]]- prev[[1]],loc[[i,2]]- prev[[2]]];
Thetaold = ArcTan[ locOld[[i,1]]- prev[[1]],locOld[[i,2]]- prev[[2]]];
Thetad = Clip[angDiff[Theta,Thetaold],Thetastep{-1,1}] ;
Theta = Thetaold+Thetad;
loc[[i]] = prev+ linklen{Cos[Theta],Sin[Theta]};
If[movement == "\<relative\>",
loc[[i+1;;]] = (loc[[i]]-locOld[[i]] +#)&/@locOld[[i+1;;]];,
angs = Table[ ArcTan[ locOld[[j,1]]- locOld[[j-1,1]],locOld[[j,2]]- locOld[[j-1,2]]],{j,i+1,7}];
Table[loc[[i+j]] = loc[[i+j-1]]+ linklen{Cos[Thetad +angs[[j]]],Sin[Thetad +angs[[j]]]},{j,1,Length[angs]}];
(*Rotate succeeding joints: first learn their angles, then apply*)
];Break[]
]];

isCollide=If[(*first 4 parts check if the robot is out of the workspace*)
Or@@((#<minX)&/@loc[[;;,1]]) ||Or@@((#>maxX)&/@loc[[;;,1]]) || Or@@((#<minY)&/@loc[[;;,2]]) ||Or@@((#>maxY)&/@loc[[;;,2]]) ,True,
Or@@Table[Or@@(segmentIntersectionQ[{{loc[[i]],loc[[i+1]]},#}]&/@listofAllLines),{i,1,Length[loc]-1}]];

If[ !isCollide, (locOld=loc; collideState =0),
If[collideState==0,
collisions=collisions+1;Beep[];collideState = 1;,
loc =locOld
]
];

Show[Graphics[{

Locator/@locOld
}],ImageSize->400]
], 
 Button["\<restart\>",collisions=0;isCollide=False;loc=locstart ;locOld=locstart;],

### [Text]
The goal of robot motion planning is to find a continuous path from an initial configuration to a goal configuration that is collision free. A configuration is a complete specification of every point of the robot. This Demonstration uses a seven-link robot with seven rotational joints that can each rotate from 0 to 2π. The resulting configuration space can be represented as a seven-dimensional torus. Obstacles in the robot's workspace map to obstacle regions in the configuration space, but computing these regions is computationally expensive. Planning for robots in high-dimensional spaces is difficult because representing the connected parts of high-dimensional spaces requires a number of samples that grows exponentially with the dimensionality of the space. This is commonly called "the curse of dimensionality."

### [Text]
\<The probabilistic roadmap method (PRM) was developed in 1996 by Lydia Kavraki et al.[1] as a general-purpose technique to solve such problems. Indeed, this Demonstration reproduces Figure 2 from[1]. PRMs generate a random roadmap that can be reused for subsequent motion-planning queries.\>
